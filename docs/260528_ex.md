## 🛠 배운 핵심 개념 (What We Learned)

- **이벤트 객체 (Event Object)**: `e.preventDefault()`를 이용해 브라우저 기본 전송 새로고침 동작을 멈추고 직접 제어하는 원리를 배웁니다.
- **LocalStorage**: 서버 없이도 브라우저에 임시 데이터를 영구히 기록/수정하여 사용자 설정을 보관하는 방식을 배웁니다.

---

## 🚀 실행 및 확인 방법 (How to Run)

1. 각 HTML 파일을 브라우저로 엽니다.
2. 마우스 클릭, 키보드 입력, 복사 버튼 클릭 시 동작하는 변화를 브라우저 화면에서 직관적으로 관찰합니다.
