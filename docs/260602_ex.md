# 웹 인증(Auth) 메커니즘, 게시판 구조 설계 & 오브젝트 스토리지 기초 🔒

고급 웹 서비스 설계에 필요한 '사용자 인증(로그인, 세션, 토큰)', 데이터를 격리 및 수집 보존하는 '게시판(Board) 게시물 생명주기 설계', 그리고 이미지를 담는 클라우드 '오브젝트 스토리지'의 동작 개요를 공부합니다.

## 🛠 배운 핵심 개념 (What We Learned)

- **웹 보안 기초**: 브라우저의 탈취 위험을 예방하기 위해 세션 저장소나 보안 쿠키를 써서 로그인을 유지시키는 아키텍처 원리를 배웁니다.
- **오브젝트 스토리지**: 왜 웹 서버 내부에 직접 이미지를 업로드하지 않고 별도의 파일 스토리지(S3, Supabase Storage 등)를 써야 하는지 학습합니다.
