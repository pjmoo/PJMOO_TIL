### 값·참조·비교 연산 이해하기

기본 타입 변수는 값을, 참조 타입 변수는 객체를 가리키는 참조 값을 담는다. 객체에 대한 ==는 같은 객체를 가리키는지 비교하고 equals는 해당 클래스가 정의한 동등성 규칙을 사용한다. String은 내용을 바꾸는 것처럼 보이는 연산도 새 문자열을 만들어 참조를 다시 대입할 수 있다.

**예시로 이해하기:** new String("java")로 만든 두 문자열은 내용은 같아도 서로 다른 객체다. 내용 비교에는 equals를 사용한다. final인 참조 변수는 다른 객체를 대입할 수 없지만, 그 객체 내부까지 항상 불변이 되는 것은 아니다.

### 반복 범위와 자료구조의 계약

배열은 길이가 고정되어 있고 인덱스는 0부터 length-1까지다. List는 순서와 중복을, Set은 중복 제거를, Map은 키로 값을 찾는 관계를 표현한다. 자료구조 선택은 문법 취향보다 필요한 조회·추가·중복 처리 방식에 따라 결정한다.

**예시로 이해하기:** 이름이 여러 번 나오는 목록의 등장 횟수는 Map<이름, 횟수>로 표현할 수 있다. 순회 조건이 i <= length이면 마지막에 범위를 벗어나므로 i < length와 비교한다. 향상된 for문의 지역 변수에 값을 대입해도 기본 타입 배열의 원소가 자동 변경되지는 않는다.

### 정답 조건과 연산량을 먼저 정하기

알고리즘은 모든 허용 입력에서 정답을 내는 절차여야 한다. 시간 복잡도는 입력 크기에 따라 작업량이 어떻게 늘어나는지를 나타내며 정확한 실행 초를 뜻하지는 않는다. 입력 상한과 자료구조의 연산 비용을 먼저 보면 무리한 반복 구조를 일찍 발견할 수 있다.

**예시로 이해하기:** 서로 다른 두 항목의 모든 조합을 검사하면 대략 n²에 비례하는 작업이 생긴다. 작은 예제로 정답을 확인한 뒤 빈 입력, 중복, 최솟값·최댓값도 살펴본다. 빠른 풀이로 바꾸더라도 같은 경계 입력에서 결과가 유지되는지를 비교한다.

### DP와 탐욕법의 선택 근거

DP는 같은 하위 문제의 결과를 저장해 재사용한다. 먼저 상태가 무엇을 뜻하는지 정의하고, 초기값과 이전 상태에서 다음 상태로 가는 점화식을 정한다. 탐욕법은 현재의 선택이 전체 최적해를 해치지 않는 근거가 있을 때 사용할 수 있다.

**예시로 이해하기:** 계단을 한 칸 또는 두 칸 오르는 경우의 수를 센다면 마지막 이동 전 위치를 나누어 이전 두 상태를 더할 수 있다. 반면 동전 문제에서 큰 동전부터 선택하는 규칙은 모든 동전 구성에 통하지 않는다. {1,3,4}로 6을 만들면 4+1+1보다 3+3이 적다.
