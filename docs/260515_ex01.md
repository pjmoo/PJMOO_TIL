# Git 로컬 · 원격 저장소 관리

## 학습 정리

- `git status`로 변경 상태를 확인하고, `git add`로 다음 커밋에 포함할 변경을 선택한다.
- `git remote add origin <URL>`로 원격을 연결하며, 첫 푸시는 `git push -u origin main`으로 upstream을 설정한다.
- `git pull`은 fetch와 merge를 함께 수행한다. 변경을 먼저 확인하려면 `git fetch`를 사용한다.

## TIL

- `add`는 파일 저장이 아니라 커밋 대상을 선택하는 단계다.
- 강제 푸시는 협업 이력을 덮어쓸 수 있으므로 피한다.
