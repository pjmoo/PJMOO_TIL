## 🛠 배운 핵심 개념 (What We Learned)

- **상속 (extends)**: 부모 클래스의 변수와 메소드를 고스란히 자식에게 상속해 코드의 중복을 제거하고 효율성을 극대화합니다.
- **접근 제어자 (Access Modifier)**: `private`, `protected`, `public` 키워드를 사용해 외부 클래스의 무분별한 필드 수정을 차단하고 Getter/Setter 메소드로 안전하게 가져오는 정보 은닉을 구현합니다.

### 참조를 복사해 전달한다는 뜻

Java는 메서드 인자를 값으로 전달한다. 객체를 넘길 때도 참조 값이 복사되므로 두 변수가 같은 객체를 가리킬 수 있다. 전달받은 객체의 상태를 변경하는 것과 매개변수에 새로운 객체를 대입하는 것은 호출자에게 미치는 영향이 다르다.

**예시로 이해하기:** 메서드에서 member의 이름을 바꾸면 호출자가 같은 객체를 보고 있어 변경을 관찰할 수 있다. 반면 member = new Member(...)는 메서드의 지역 참조만 바꾼다. 생성자는 처음부터 유효한 상태를 만들고, 이후의 상태 변경은 목적이 드러나는 메서드로 제한한다.

### 캡슐화는 변경 규칙을 지키게 하는 설계

필드를 private으로 숨겨도 모든 값을 자유롭게 바꾸는 setter를 제공하면 업무 규칙을 지키기 어렵다. 캡슐화는 객체가 유효한 상태를 유지하도록 변경 경로를 통제하는 것이다. 상속은 코드 재사용뿐 아니라 부모 타입의 약속을 자식이 지킨다는 관계를 전제로 한다.

**예시로 이해하기:** 포인트를 임의의 숫자로 덮어쓰는 setter 대신 적립·사용 메서드에서 음수와 잔액 부족을 검사할 수 있다. 단순히 다른 객체의 기능을 이용하는 관계라면 상속보다 필드로 보유하는 합성이 변경 영향을 줄일 수 있다.
