# 생성형 AI · 개발 환경 · Git 기초

## 학습 정리

- 생성형 AI는 텍스트·이미지·코드 같은 결과를 생성하며, LLM은 다음 토큰을 예측하는 대규모 언어 모델이다.
- AI 응답은 확률적이므로 환각·지식 최신성·맥락 이탈을 검증 절차와 검색/RAG로 보완한다.
- 프롬프트에는 역할, 작업, 맥락, 출력 형식, 예시를 포함하면 결과의 재현성을 높일 수 있다.
- Git은 Working Directory → Staging Area → Local Repository 순서로 변경을 관리한다.

## TIL

- AI는 정답 보증 도구가 아니라 검증 가능한 초안을 빠르게 만드는 도구다.
- 커밋은 작은 작업 단위와 명확한 메시지로 남긴다.
