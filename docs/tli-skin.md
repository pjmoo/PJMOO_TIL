# 티스토리 스킨 배포 규격본 🎨

티스토리 블로그 관리자 페이지에 즉석으로 업로드하여 사용할 수 있도록 치환자 세팅을 정리한 순수 블로그 배포용 정적 에셋 폴더입니다.

---

## 📂 학습 파일 구성 (Files)

- [skin.html](file:///C:/workspace/tli-skin/skin.html) : 티스토리 데이터 매핑용 메인 XML/HTML 파일
- [style.css](file:///C:/workspace/tli-skin/style.css) : 블로그 레이아웃 테마 스타일시트
- [index.xml](file:///C:/workspace/tli-skin/index.xml) : 스킨 이름 및 상세 옵션 메타데이터 정의 파일

---

## 🛠 배운 핵심 개념 (What We Learned)

- **스킨 배포 명세**: 티스토리 관리자 환경에 호환되어 정상적으로 테마 옵션이 출력되도록 `index.xml` 규격을 통제하는 법을 학습합니다.
