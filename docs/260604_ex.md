# Node.js & Express 백엔드 프레임워크 & Gemini AI SDK 연결 실습 🚀

클라이언트 웹 브라우저를 벗어나 컴퓨터 내에서 독자적인 웹 서버를 구현하는 `Node.js`와 `Express` 서버 프레임워크 기초, 그리고 구글의 대형 언어 모델(Gemini) API를 연동하여 AI 챗봇의 백엔드 통로를 직접 구축해 보는 프로젝트입니다.

---

## 📂 학습 파일 구성 (Files)

- [package.json](file:///C:/workspace/260604_ex/package.json) : 필요한 모듈(express, @google/generative-ai 등)을 명시한 백엔드 종속성 파일
- [01_express.js](file:///C:/workspace/260604_ex/01_express.js) : 포트를 열고 브라우저의 접속을 가로채 응답하는 익스프레스 서버의 뼈대 소스코드
- [02_sdk.js](file:///C:/workspace/260604_ex/02_sdk.js) : 구글 Gemini API를 내 키값과 연동해 터미널에 결과를 가져와보는 자바스크립트 모듈 파일
- [03_chat.js](file:///C:/workspace/260604_ex/03_chat.js) : 대화 이력을 기억하고 챗봇 응답을 던져주도록 커스터마이징한 자바스크립트 파일
- [public/index.html](file:///C:/workspace/260604_ex/public/index.html) : Express 백엔드 서버와 연동하여 사용자가 직접 텍스트를 입력하고 AI 답변을 받는 챗봇 화면

---

## 🛠 배운 핵심 개념 (What We Learned)

- **웹 백엔드 라우팅**: 클라이언트가 `/` 혹은 `/api/chat` 같은 주소로 접근했을 때, 특정 함수를 발동시켜 웹페이지를 띄우거나 JSON 정보를 리턴하는 API 서버 설계법을 습득합니다.
- **환경변수 (.env) 관리**: API 인증키와 같이 코드에 직접 드러나면 안 되는 비밀값들을 시스템 메모리에 숨겨 가져오는 법을 배웁니다.

---

## 🚀 실행 및 확인 방법 (How to Run)

1. 터미널을 열고 라이브러리를 설치합니다: `npm install`
2. 환경변수 템플릿 파일인 `.env.sample`을 복사해 `.env` 파일을 만들고, 발급받은 Gemini API 키값을 입력합니다.
3. 백엔드 서버를 작동시킵니다: `node 01_express.js` 또는 `node 03_chat.js`
4. 브라우저로 `http://localhost:3000`에 접속하여 실시간 연동 상태를 확인합니다.
