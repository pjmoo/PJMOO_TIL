# 나의 첫 자바(Java) 프로그램 - 개발 환경 구축 ☕

자바 언어 학습의 첫날로, JDK 설치 및 IDE(IntelliJ) 연동을 확인하고 화면에 글자를 출력하는 콘솔 프로그램의 뼈대를 만드는 실습 프로젝트입니다.

---

## 📂 학습 파일 구성 (Files)

- [src/Main.java](file:///C:/workspace/260616_first-java/src/Main.java) : 가장 기본적인 진입점인 `main` 메소드 안에 화면 출력을 실행해 보는 메인 소스코드

---

## 🛠 배운 핵심 개념 (What We Learned)

- **JVM & JDK**: 자바 프로그램이 실행되는 기본 엔진인 가상 머신(JVM)과 개발 도구(JDK) 환경을 이해합니다.
- **진입 메소드**: 자바 애플리케이션의 시작을 알리는 `public static void main(String[] args)` 문법의 형식을 배웁니다.

---

## 🚀 실행 및 확인 방법 (How to Run)

1. IntelliJ IDEA 등 IDE에서 본 프로젝트 폴더를 엽니다.
2. [Main.java](file:///C:/workspace/260616_first-java/src/Main.java) 파일을 마우스 우클릭 후 **Run 'Main.main()'**을 실행하여 터미널 콘솔창에 나타나는 문구를 확인합니다.
