### 소스 작성·컴파일·실행 환경 구분하기

자바 소스는 컴파일을 거쳐 바이트코드가 되고 JVM이 이를 실행한다. IDE에서 선택한 JDK와 터미널의 java·javac가 다르면 같은 파일도 다른 결과를 낼 수 있다. 실행 환경 문제를 코드 문법 문제와 분리하려면 먼저 버전과 진입점, 패키지와 클래스 경로를 확인한다.

**예시로 이해하기:** HelloWorld가 IDE에서는 실행되는데 터미널에서는 실패한다면 파일 내용부터 바꾸기보다 사용 중인 JDK, 컴파일 결과 위치, 실행한 클래스 이름을 비교한다. TIL에는 오류 메시지와 설정 변경 전후를 남기면 원인을 재현할 수 있다.

### 값·참조·비교 연산 이해하기

기본 타입 변수는 값을, 참조 타입 변수는 객체를 가리키는 참조 값을 담는다. 객체에 대한 ==는 같은 객체를 가리키는지 비교하고 equals는 해당 클래스가 정의한 동등성 규칙을 사용한다. String은 내용을 바꾸는 것처럼 보이는 연산도 새 문자열을 만들어 참조를 다시 대입할 수 있다.

**예시로 이해하기:** new String("java")로 만든 두 문자열은 내용은 같아도 서로 다른 객체다. 내용 비교에는 equals를 사용한다. final인 참조 변수는 다른 객체를 대입할 수 없지만, 그 객체 내부까지 항상 불변이 되는 것은 아니다.
