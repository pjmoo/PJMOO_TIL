# FatDog AI 확장 실습 플랫폼 🍃🤖

## 📂 학습 파일 구성 (Files)

- [pom.xml](file:///C:/workspace/Fatdogaiex/pom.xml) : 프로젝트 의존성 설정 파일
- [src/main/java/](file:///C:/workspace/Fatdogaiex/src/main/java/) : AI 쿼리를 수행하고 결과를 응답받는 컨트롤러 및 도메인 로직
